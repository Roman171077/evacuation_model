# Evacuation model (Приложение №7, приказ МЧС №1140)

Одномерная дискретно-шаговая модель эвакуации:
- люди движутся по связанным участкам;
- на каждом шаге формируются локальные группы;
- по локальной плотности рассчитывается скорость;
- переход через выход ограничен пропускной способностью;
- при переполнении образуется очередь перед выходом.

## Структура проекта

- `src/model/` — модели `Person`, `Segment`, `SimulationParams`.
- `src/simulation/grouping.py` — формирование локальных групп.
- `src/simulation/formulas.py` — инженерные формулы и коэффициенты.
- `src/simulation/simulation.py` — ядро `EvacuationModel` (`step`, `run`).
- `scenarios/` — сценарии, возвращающие `(sections, people, params)`.
- `main.py` — совместимый entrypoint, перенаправляющий запуск на `main2.py`.
- `main2.py` — сценарий геометрического формирования рядов и orchestration CLI.
- `src/rows_model.py` — расчетная часть формирования рядов, истории состояний и сценарии.
- `src/visualization.py` — отдельный компонент визуализации на matplotlib.

## Инженерные допущения (зафиксированы явно)

1. Плотность участка `D_vj` вычисляется **без `dt`**:
   `D_vj = (N_j * f_avg) / (a_j * b_j)`.
2. Локальные группы строятся **цепочкой соседей** с условием расстояния `< 0.25 м`.
3. Снижение скорости от плотности выполняется функцией `density_reduction_factor`,
   пока не задана табличная зависимость из методики.
4. Интенсивность берётся как `q = V * D`, где `V` в м/мин.

## Ограничения модели

- модель одномерная (координата `x`);
- не учитываются обгоны и 2D-маневрирование;
- не моделируются психологические эффекты и сопровождение;
- очередь моделируется координатами ожидания у выхода.
- в `main2.py` этап формирования потока отделен от расчета плотности: ряд определяется по `c_geom`, а вместимость ряда по ширине — по `a_geom` и `Segment.width`.

## Запуск

```bash
python main.py
python main2.py --mode realtime
```

Для `main2.py` на Windows принудительно выбирается интерактивный backend `TkAgg`, а в headless Linux/macOS без `DISPLAY`/`WAYLAND_DISPLAY` используется `Agg`, поэтому при старте выводится активный backend matplotlib.

## Минимальный сценарий

Сценарий `scenarios/test_case_1.py` содержит:
- коридор шириной 2.0 м;
- дверь 0.9 м;
- 8 человек;
- смешанный состав групп (включая `WHEELCHAIR`).

## Результат симуляции

`EvacuationModel.run()` возвращает:
- `total_evacuation_time_sec` — общее время эвакуации;
- `finished_count` — число эвакуированных;
- `total_people` — число людей в сценарии;
- `exit_times` — время выхода каждого человека по `pid`.
