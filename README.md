# Evacuation model (Приложение №7, приказ МЧС №1140)

Одномерная дискретно-шаговая модель эвакуации:
- люди движутся по связанным участкам;
- на каждом шаге формируются локальные группы;
- по локальной плотности рассчитывается скорость;
- переход через выход ограничен пропускной способностью;
- при переполнении образуется очередь перед выходом.

## Структура проекта

- `src/catalog/profiles.py` — нормативные профили потока, цветовые справочники и функции доступа к параметрам.
- `src/model/` — доменные модели (`Person`, `Segment`, `SimulationParams`, `Snapshot`, визуальные dataclass-структуры).
- `src/row_layout.py` — геометрическое формирование рядов на участке.
- `src/visualization/` — визуализация, раскладка на плоскости и анимация matplotlib.
- `scenarios/` — сценарии, возвращающие `(sections, people, params)`.
- `main.py` — запуск demo-сценария, расчет симуляции и orchestration CLI.

## Инженерные допущения (зафиксированы явно)

1. Плотность участка `D_vj` вычисляется **без `dt`**:
   `D_vj = (N_j * f_avg) / (a_j * b_j)`.
2. Локальные группы строятся **цепочкой соседей** с условием расстояния `< 0.25 м`.
3. Снижение скорости от плотности выполняется функцией `density_reduction_factor`,
   пока не задана табличная зависимость из методики.
4. Интенсивность берётся как `q = V * D`, где `V` в м/мин.

## Ограничения модели

- модель одномерная (координата `x`);
- не учитываются обгоны и 2D-маневрирование;
- не моделируются психологические эффекты и сопровождение;
- очередь моделируется координатами ожидания у выхода;
- этап формирования потока отделен от расчета плотности: ряд определяется по `c_geom`, а вместимость ряда по ширине — по `a_geom` и `Segment.width`.

## Запуск

```bash
python main.py
python main.py --mode snapshot
```

Для визуализации на Windows принудительно выбирается backend `TkAgg`, а в headless Linux/macOS без `DISPLAY`/`WAYLAND_DISPLAY` используется `Agg`, поэтому при старте выводится активный backend matplotlib, если библиотека установлена.

## Минимальный сценарий

Сценарий `scenarios/simple_case.py` содержит:
- коридор шириной 2.0 м;
- дверь 1.2 м;
- 1 человека профиля `M0_7`.

## Результат симуляции

`run_simulation()` / `run_simulation_with_history()` возвращают:
- `travel_time_sec` — общее время прохода до выхода;
- `finished_count` — число эвакуированных;
- `total_people` — число людей в сценарии;
- `exit_times` — время выхода каждого человека по `pid`.
