# Evacuation Model

Проект реорганизован в модульную структуру:

- `src/model` — сущности модели (`Person`, `Segment`, `Door`)
- `src/simulation` — логика симуляции
- `src/utils` — общие константы
- `scenarios` — готовые сценарии запуска
- `main.py` — точка входа

## Запуск

```bash
python main.py
```
